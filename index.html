จุดแข็ง

  • มีความรับผิดชอบ
  • เรียนรู้เครื่องมือใหม่ได้เร็ว
  • ทำงานเป็นทีมและรับฟังความเห็นผู้อื่น
  • ใส่ใจรายละเอียดของงาน

สิ่งที่กำลังพัฒนา

  • ประหม่าเมื่อต้องนำเสนอหน้าชั้น - กำลังฝึกด้วยการอาสาเป็นผู้นำเสนอ
  • Cloud Security - เข้าอบรมหลักสูตร/ความรู้ที่เกี่ยวข้องตามแนวทางหรือประกาศของ กมช.
  • พัฒนาทักษะ SQL - ศึกษาการเขียน SQL ตั้งแต่พื้นฐาน และการนำไปใช้ในการจัดการและวิเคราะห์ข้อมูล
